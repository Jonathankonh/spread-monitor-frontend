# Spread Monitor – Frontend

Vue.js Dashboard zur Visualisierung von Preis- und Spread-Daten aus mehreren Boersen (gettex, Xetra, LS Exchange, EIX). Konsumiert die REST-API des Spread-Monitor-Backends.

## Project Setup

npm install

### Compile and Hot-Reload for Development

npm run dev

### Type-Check, Compile and Minify for Production

npm run build
